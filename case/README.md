# Case

An in-line cord unit: Martin's own printed case in a UL94 V-0 flame-retardant filament, with cable
glands and cord grips, a button cap and a light pipe. Never plain PLA or PETG for the mains
enclosure. The whole board is at mains potential, so the case is the safety barrier: nothing
conductive passes through it. The board's outline, holes, heights and openings are in
`pcb/out/petro/case-interface.json`. Work item: PETRO-6.
